# Heritage Echoes

You are a senior creative director, award-winning web designer, UX strategist and

frontend engineer specializing in cinematic luxury hospitality websites.

Build a completely original, production-quality luxury heritage hospitality website.

REFERENCE:

Use https://www.theornate.in/ only as a reference for information architecture,

cinematic pacing, immersive storytelling and sophisticated GSAP-based interaction.

IMPORTANT:

DO NOT CLONE THE ORNATE WEBSITE.

DO NOT COPY ITS TEXT.

DO NOT COPY ITS EXACT VISUAL DESIGN.

DO NOT RECREATE ITS BRAND IDENTITY.

Instead, create a completely original identity based on:

REAL INDIAN VINTAGE + HERITAGE ARCHITECTURE + ROYAL ESTATE + EDITORIAL LUXURY +

ARCHIVAL PHOTOGRAPHY + CINEMATIC STORYTELLING.

The website should feel like entering an old, prestigious Indian estate whose

history has been carefully preserved.

The experience should feel:

quiet,

cinematic,

architectural,

editorial,

warm,

nostalgic,

expensive,

immersive,

and timeless.

Do NOT make it look like a generic luxury hotel template.

ANIMATION SYSTEM

==================================================

GSAP is the primary animation system.

Use ScrollTrigger extensively but intelligently.

Animation principles:

1. Every major section should have a cinematic entrance.

2. Do not animate every element.

3. Create hierarchy.

4. Use slow movement for emotional sections.

5. Use faster transitions for navigation and micro-interactions.

6. Avoid random motion.

7. Animation should communicate storytelling.

Use:

gsap.timeline()

ScrollTrigger

scrub

pin

clipPath

scale

opacity

x/y transforms

parallax

stagger

text splitting

Hero:

image scale

word/line reveal

Images:

parallax

Timeline:

pin + scrub

Gallery:
